# Модуль резервного копирования БД для SupportDesk

Три новых файла в папке `modules\` и три правки по одной строке в существующих файлах.
Таблицы БД и существующие формы не меняются.

## Что делает модуль
- **Автоматически:** копия `teh_db.db` создаётся при запуске приложения, при выходе и по расписанию (по умолчанию каждые 4 часа). Если база не менялась с последней копии, новая не создаётся.
- **По кнопке:** в окне «Настройки» (ADMIN) появилась группа «Резервные копии» → «Управление копиями»:
  - создать копию сейчас, открыть папку копий;
  - восстановить из выбранной копии или из файла (с подтверждением и автоматической страховочной копией текущей базы `prerestore_*.db`);
  - настройки: автокопирование вкл/выкл, интервал, сколько копий хранить (по умолчанию 10), дополнительная папка (флешка, сетевой диск).
- Копии лежат в папке `backups\` рядом с `SupportDesk.exe`: `teh_db_2026-10-08_14-30-00.db`.
- Журнал модуля: `backups\backup.log`. Ручные действия также пишутся в общий `logs.txt` в формате приложения.
- Копирование идёт через API резервного копирования SQLite, поэтому копия целостная даже при одновременной записи; каждая копия проверяется (`PRAGMA integrity_check`). При восстановлении выбранный файл проверяется на целостность и на наличие всех таблиц текущей базы.

## Установка
0. **Сделайте копию всей папки проекта и файла `teh_db.db`.** Начинайте на копии.
1. Скопируйте папку `modules` в папку проекта (рядом с `Program.cs` и папкой `forms`).
2. Три правки:

**`SupportDesk.csproj`**: после строки `<Compile Include="Program.cs" />` добавьте
```xml
    <Compile Include="modules\BackupService.cs" />
    <Compile Include="modules\BackupForm.cs" />
    <Compile Include="modules\SettingForm.Backup.cs" />
```
(Либо в Visual Studio: «Показать все файлы» → ПКМ по `modules` → «Включить в проект».)

**`Program.cs`**, метод `Main`: перед `Application.Run(new PreLoaderForm());` добавьте
```csharp
modules.BackupService.Start();
Application.ApplicationExit += (s, e) => modules.BackupService.Stop();
```

**`forms\SettingForm.cs`**, метод `SettingForm_Load`: после `LoadingWidgets();` добавьте
```csharp
InitBackupUi();
```
3. Соберите проект.

## Проверка
1. Запустите приложение: в `bin\...\backups\` должен появиться файл `teh_db_*.db`.
2. Войдите как ADMIN → «Настройки» → «Управление копиями» → «Создать копию сейчас».
3. Измените что-нибудь в базе (например, добавьте контакт) → «Восстановить из выбранной» → выберите копию до изменения → подтвердите → перезапустите приложение. Изменение должно исчезнуть, а в `backups\` появится `prerestore_*.db`.
4. Закройте приложение и проверьте, что копия при выходе создана (если база менялась).

## Откат
Удалите три добавленные правки и папку `modules`, соберите проект заново. Папку `backups\` можно оставить или удалить.

## Что известно о проверке
Код скомпилирован компилятором Mono (C# 7) вместе с `System.Data.SQLite` из вашего проекта, ошибок нет. Запуск на Windows с реальной БД я выполнить не мог, поэтому шаги из раздела «Проверка» нужно пройти у себя.

## Ограничения
- Копии на том же диске не защищают от выхода диска из строя: для этого задайте «Дополнительную папку».
- После восстановления приложение нужно перезапустить (данные текущего пользователя кэшируются в памяти).
- Если приложение закрыто аварийно (процесс убит), копия «при выходе» не создаётся; останется копия при запуске и по расписанию.
